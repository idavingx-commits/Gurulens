## About GuruLens

**GuruLens** is an emerging EdTech project that aims to make it easier for students in Sri Lanka to discover educators, explore learning opportunities, and connect with educational communities in one place.

Rather than functioning solely as a teacher directory, GuruLens is envisioned as a thoughtful combination of **teacher discovery, student feedback, educational content, and social learning**.

## What we're building

| Area | Vision |
| :--- | :--- |
| 🔎 **Teacher discovery** | Explore educators by subject, grade, and location. |
| 👩‍🏫 **Educator profiles** | See teaching information, educational posts, and class updates. |
| ⭐ **Student feedback** | Help students make informed choices through responsibly moderated ratings and reviews. |
| 🎥 **Learning content** | Educational posts, short-form videos, and longer lessons. |
| 🤝 **Educational community** | Follow educators and engage with learning-focused content. |
| 🛡️ **Trust & safety** | Teacher verification, moderation, privacy, and role-based administration. |

*These items describe the product vision. Some features may be incomplete, experimental, or unavailable in the current build.*

## Project status

> [!IMPORTANT]
> **Prototype / Active Development** — GuruLens is **not yet a production-ready service**. The current work is intended for concept validation, interface development, and functional testing. Do not assume that all planned features, security controls, or integrations are live.

Current priorities include:

- Refining the user experience across mobile and desktop.
- Turning prototype interactions into reliable, persistent workflows.
- Building secure account, verification, review, and moderation processes.
- Testing performance, accessibility, and data protection before public release.

## Product principles

- **Education first:** useful educational experiences over engagement for its own sake.
- **Fairness:** transparent feedback and verification processes; no paid-for ratings.
- **Student safety:** privacy-conscious design, age-appropriate protections, and content moderation.
- **Trust:** distinguish verified identity from popularity, activity, or review scores.
- **Performance:** lightweight, responsive interfaces that work well on mobile devices.

## Development

GuruLens is being developed independently with hands-on planning, design direction, and implementation work, using modern development workflows and **OpenCode-assisted development** where helpful.

**Developers:** If you have access to this repository's source code, consult the project files for the *actual* framework, scripts, environment requirements, and setup steps. This README intentionally avoids unverified build commands or infrastructure claims.

> [!CAUTION]
> Never commit `.env` files, passwords, API keys, service credentials, private student information, or production database exports. Any prototype data must be fictitious or appropriately consented to and protected.
